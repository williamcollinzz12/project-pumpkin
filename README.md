# Chicago Pumpkin Authority

Premium pumpkin porch arrangements for Lincoln Park, Chicago.

**Live Site:** https://williamcollinzz12.github.io/project-pumpkin/

## About

We deliver, arrange, and style pumpkins on customers' front porches so they get a beautiful fall display without doing any work. Packages range from $449 to $849.
