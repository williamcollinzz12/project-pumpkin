# Chicago Pumpkin Authority — Website

## What's in this folder

This is the working website for chicagopumpkinauthority.com.

- **index.html** — The full single-page website (HTML, CSS, and JS all in one file). Open this in a browser to preview.
- **images/** — Photos used on the site. Right now these are sample/placeholder images to get a feel for the layout. We'll swap them for real photos of our own work before launch.
