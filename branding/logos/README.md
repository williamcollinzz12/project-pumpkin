# Chicago Pumpkin Authority — Logo Files

Drop all logo files into this folder. Here's what we need:

## Logo Versions to Collect

| File Name | Background | Use Case |
|-----------|-----------|---------|
| logo-light.png | White / light | Website, emails, print |
| logo-dark.png | Dark / black | Dark website sections, social media |
| logo-icon.png | Transparent | Profile picture, favicon, app icon |
| logo-horizontal.png | White / light | Website header / nav bar |
| logo-horizontal-dark.png | Dark / navy | Website header on dark backgrounds |
| logo-black.png | White | Single-color printing, embroidery |
| logo-white.png | Dark | Reversed/knockout use |

## Notes
- Always use PNG with a transparent background where possible
- Keep the original source file (AI, SVG, or PSD) so you can resize without losing quality
- The icon-only version (just the pumpkin, no text) is the most important for social media
